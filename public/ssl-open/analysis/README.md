# SSL Open Analysis Charts

This directory should contain the following chart images referenced by the analysis page:

1. `ev_by_tier.png` - Expected value by tier (Normal/Hard/God)
2. `matthew_ev.png` - Matthew McAlear EV by tier × DD strategy  
3. `dd_breakeven.png` - Double Down breakeven analysis
4. `win_prob_by_tier_choice.png` - Win/top-3 probability by tier
5. `standings_context.png` - Current season standings (top 12)
6. `stroke_penalty_tornado.png` - Stroke penalty sensitivity analysis
7. `fairness_gini.png` - Inequality of Open EV & season-leader capture
8. `points_distribution.png` - Points distribution under mix B

These images should be 1200×750px (or similar 16:10 aspect ratio) PNG files.

The analysis page is live at `/ssl-open/analysis` and will display these charts once they're added to this directory.
